# Customer Segmentation & Quantitative Business Analytics Framework

## Overview
This project implements an end-to-end Customer Segmentation and KPI Analytics Framework using Python and SQL. The objective is to analyze customer transaction behavior, identify high-value customers, and generate actionable business insights to support data-driven decision-making.

This framework simulates real-world analytics workflows used in banking, fintech, and digital platforms.

---

## Business Objectives

• Identify High, Medium, and Low value customers  
• Analyze revenue contribution across customer segments  
• Develop KPI tracking framework  
• Enable data-driven customer targeting strategies  
• Support business performance optimization  

---

## Tech Stack

• Python (Pandas, Matplotlib, Seaborn)  
• SQL (SQLite)  
• Google Colab  
• GitHub  

---

## Key KPIs Developed

• Total Customer Spend  
• Transaction Frequency  
• Average Transaction Value  
• Revenue Contribution by Segment  
• Customer Distribution by Segment  

---

## Segmentation Methodology

Customers were segmented using quantile-based segmentation (qcut) based on total spend:

• High Value Customers  
• Medium Value Customers  
• Low Value Customers  

This ensures statistically balanced segmentation for performance comparison.

---

## Key Insights

• High Value customers contribute the majority of total revenue  
• Customer spend follows a right-skewed distribution  
• Transaction frequency positively correlates with revenue  
• A small percentage of customers generate disproportionate business impact
